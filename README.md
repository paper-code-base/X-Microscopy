# X-Microscopy

**Protocol for performing STORM-like superresolution image reconstruction from conventional microscopy with deep learning-based X-Microscopy**

## Overview

 This protocol provides comprehensive instructions on model implementation for performing STORM-like superresolution image reconstrcuction from wide-field images (WFs) of biological structures  with X-Microscopy. The execution of X-Microscopy can be divided into UR-Net-8 training, UR-Net-8 testing, X-Net training, X-Net testing, and performance evaluation of X-Microscopy.

## Start here

### Hardware and software requirements

The following protocol is configured for windows or Ubuntu with Python 3.7.0 and TensorFlow 1.15.0. The experiments in our study were carried out on a system equipped with 64GB of RAM and a single 11GB NVIDIA GeForce GTX 1080 GPU.

### Environment configuration and dependency installation

a. Set up the required Python dependencies with this link: https://www.anaconda.com/download

b. Installing X-Microscopy pipeline.

```
cd [your_project_folder_name]
git clone https://github.com/paper-code-base/X-Microscopy
cd X-Microscopy
```

c. Setting up and activating a Python 3.7.0 virtual environment with Conda.

```
conda create --name X-Microscopy python=3.7.0
conda activate X-Microscopy
```

d. Install all Python libraries required by the project.

```
cd X-Microscopy
pip install -r requirements.txt 
```

### UR-Net-8 training

a. The project stores data in the 'X-Microscopy/dataset' directory under the ‘training-example-data’ and ‘test-example-data’ folders. Please ensure that the training and test datasets are named the same as the example data we provided.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd dataset
>tree /a
training-example-data
└── 1
    ├── F-SRM
    ├── U-SRM
    ├── W-SRM
    └── wf
└── 2
    ├── F-SRM
    ├── U-SRM
    ├── W-SRM
    └── wf
...
└── n
    ├── F-SRM
    ├── U-SRM
    ├── W-SRM
    └── wf
test-example-data
└── 1
    ├── F-SRM
    └── wf
└── 2
    ├── F-SRM
    └── wf
...
└── n
    ├── F-SRM
    └── wf
```

b. Open the terminal and navigate to the 'X-Microscopy/UR-Net-8' directory.

```
>cd..
>cd UR-Net-8      # Change to the "UR-Net-8" directory.
```

c. Start the training process by   running ‘python main.py  --phase  train  --same_input_size  1’.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd UR-Net-8
>python main.py  --phase  train  --same_input_size  1
```

d. Please open another command prompt and run the following command to start TensorBoard. Then open your browser and go to http://localhost:6006/ to view the training process.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>conda acitvate X-Microscopy
>cd UR-Net-8
>tensorboard --logdir  logs
```

### UR-Net-8 finetuning

 Fine-tune the UR-Net-8 model using the following commands.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd UR-Net-8
>python main.py  --phase  train  --same_input_size  0 
```

### Performing inference on test images using the trained UR-Net-8

a. Initiate the testing process by executing ‘python main.py  --phase  test’.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd UR-Net-8
>python main.py  --phase  test
```

Note: After testing the test set, run the following commands to test ‘training-example-data’. This step is intended to generate MU-SRM data for X-Net training. 

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd UR-Net-8
>python main.py --phase test --test_dataset_name ../dataset/training-example-data 
```

### X-Net training

a. Open the terminal and navigate to the "X-Microscopy/X-Net" directory.

```
cd X-Microscopy
cd X-Net
```

Note: X-Net training utilizes WF images and MU-SRM images generated by UR-Net-8 as inputs, with W-SRM images as the ground truth.

b. Start the training process by running ‘python main.py  --phase  train  --same_input_size  1’.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd X-Net
>python main.py  --phase  train  --same_input_size  1
```

Note: Open a new command prompt and execute the following command to launch TensorBoard. After that, access http://localhost:6006/ in your browser to monitor the training process.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>conda acitvate X-Microscopy
>cd X-Net
>tensorboard --logdir  logs
```

### X-Net finetuning

a. Fine-tune the X-Net model using the following commands.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd X-Net
>python main.py  --phase  train  --same_input_size  0 
```

### X-Net testing

a. Start the testing process by running the following command.

```
>cd X-Microscopy # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd X-Net
>python main.py  --phase  test
```

## The X-Microscopy performance evaluation

 a.    Run the command ‘python evaluate_test.py’ in the terminal.

```
>cd X-Microscopy  # Ensure you are in the "X-Microscopy" directory; if you are already in this directory, skip this step.
>cd X-Net
>python evaluate_test.py
```

b.    After executing the command, you will get SSIM values of XM1, XM2, and XM3 correspond to the three outputs of X-Net. The SSIM value of XM3 is the final SSIM value obtained in this project.
